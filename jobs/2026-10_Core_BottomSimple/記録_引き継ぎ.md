## 2. 再開手順

### 2-1. 使用者の作業（機械側）
1. エア供給を確認する。コンプレッサーが動いているか、元バルブが開いているか、機械側のレギュレーターがATC（ZAT-540）の規定圧か（規定値は本体ラベルか紙の説明書で確認）、ホースの外れや漏れがないか。後付けのエアノズルが同じ配管にあるなら閉じる。
2. 工具の状態を目で確認する。主軸に何番が付いているか、マガジン1番に6 mmが戻っているか、ATC3にPRB2.0-21があるか、工具が落ちていないか。交換の途中で引っかかっている場合は、手で無理に抜かない。
3. エアが戻ったら［Clear Error］→**［Stop Cutting］（切削中止）**。Resumeは押さない（02はまだ何も削っていない）。
4. 01で出た溝の切りくずを掃除機で吸う（エアブローは禁止）。

### 2-2. CLI側の作業（使用者から中止完了の連絡を受けてから）
```
cd D:\UEC\QDD\MDX-540\cam_output
python queue_ctl.py status          # 空であることを確認
python queue_ctl.py send Core_02_T3_gap_shiftX-10Y-5.rml Core_03b_T1_outer_trochoid_shiftX-10Y-5.rml
```
`send` はキューが空でないと送らない。送信後にプリンタの一時停止を自動で解除する。実機が動くコマンドなので、Claude Codeの自動モードでは許可が必要になる（拒否されたら、使用者に `/permissions` で許可してもらうか、`!` で使用者自身に実行してもらう）。

### 2-3. 02と03bの合間
02が終わり、03b先頭のJ1（6 mmへ戻す交換）に入る前に、使用者がVPanelで一時停止して切りくずを吸う。03bの終盤で外周が貫通すると、部品は接着剤だけで保持された状態になる。

## 3. 絶対に守ること（実際に起きた事故に近い事例から）
- **機械側で中止（Stop Cutting）する前に、必ず `python queue_ctl.py purge` でキューを空にする。** 中止で消えるのは機械のバッファだけで、Windowsはファイルの続きを送り続ける。そうなると工具交換も主軸起動もないまま、途中の移動指令が実行される。
- **キューの一時停止では、送信中のジョブは止まらない。** 実際に、一時停止したあとも02が約260 KB機械へ流れた。止めたいときはpurgeする。
- 送る前に必ず `status` でキューが空であることを確認する（二重送信の防止）。
- 機械が見えるのは使用者だけ。送信後は「位置・音・切りくず」の確認を必ず使用者に頼む。
- 切削油とエアブローは使わない（MDX-540の取扱説明書で禁止）。

- プログラム上の原点は、素材の左手前角をXY0、素材上面をZ0とする。**実際の機械原点は、素材左手前角から約+10 mm（右）、+5 mm（奥）ずれている**（使用者の目視の推定）。そのためshift版を使っている。部品中心は機械のユーザー座標でX40、Y45。
- ATC1は6 mmフラット（3枚刃、メーカー不明）、ATC3はPRB2.0-21（2 mmボール、突出し30 mm）。工具長は登録済み。
- 初回（補正なし）の送信は、位置ずれのため中止した。そのとき、本来の位置から約11 mm離れたInnerハブの範囲に、中央穴のヘリカル加工の跡が残っている。使用者は確認したうえで続行を判断した。

## 5. 加工内容と条件（詳細は `cam_output\README.md`）
- 部品はInner/Outer Coreを反転し、同心に配置したもの。機械座標でZ0〜-7はOuterリング r35〜40、Z0〜-8はInnerハブ r22（中央穴Ø10）。下側はInner歯 r≤28、Outer歯 r≥32。両者の間は4 mm溝。歯溝（約1 mm）は加工できず、つぶれる（使用者が許容済み）。
- 01（6 mm、4800 rpm、ap0.3、F280）: 中央穴を貫通、r22〜35をZ-7.0まで荒取り、壁面仕上げ。**このときびびり音とバリが出た。**
- 02（2 mmボール、12000 rpm、ap0.15、F200）: Inner根元と歯先の傾斜（Z-7〜-8）、4 mm溝 r28〜32 をZ-16（捨て板に1 mm）まで貫通。
- 03b（6 mm、トロコイド、溝幅8 mm、ap約0.96、1ループ0.4 mm送り、F420）: 外周 r40 を貫通して切り離し。外周仕上げはスプリングパス付き。びびり対策として全幅スロットから変更した。
- びびり調整: VPanelの主軸オーバーライド（85〜90%を試す）と送りオーバーライドで調整する。静かになる組み合わせが見つかれば、その条件で03bを作り直す（`cam.py` の `T1` と `job03b`）。

## 6. 再生成の方法
```
cd D:\UEC\QDD\MDX-540\cam_output
python -c "import cam; cam.CX, cam.CY = 40.0, 45.0; p = cam.job03b(); cam.to_rml(p, 'Core_03b_T1_outer_trochoid_shiftX-10Y-5.rml')"
```
- `cam.py`: パス生成（job01 / job02 / job03 / job03b）と、RML出力の `to_rml`。座標は部品中心が基準。`CX, CY` が機械上の部品中心（補正なしは50,50、今回は40,45）。
- `sim.py`: 高さマップによる除去シミュレーション。`simulate([(path, D, ball), ...])` で、早送りで材料に当たる移動と最大切込みを出す。`part_height()` はモデルの高さマップ（初回は数十秒かかり、作業ディレクトリに `parth.npy` を作る）。
- `geom.py`: STLの断面（機械座標＝反転）。
- RML: `;;^DF` / `J<n>`（ATC）/ `!RC<0-15>`（3000〜12000 rpm、600 rpm刻み）/ `!MC1` / `V<mm/s>` / `Z x,y,z`（0.01 mm単位、ユーザー原点基準）。FusionのRoland RMLポスト（MDX-540設定）と同じ書式。

## 7. 残作業
1. 02と03bを最後まで流す（上の手順どおり）。
2. 部品を外す（アセトンか熱で接着を緩め、テープを剥がす）。上面の縁のバリを取る。Innerハブ根元のR1すみは仕様として残る。
3. **Bottom_Simple（SUS430、2 mm板）は未着手。** 外径80、中央穴Ø10、外周から幅約5 mmの切り欠きがある。6 mm工具は切り欠きに入らない。別の段取り（板の固定、原点設定）が必要。
4. 次の段取りでは原点を正しく設定し、補正なしの座標（CX, CY = 50, 50）で作る。
