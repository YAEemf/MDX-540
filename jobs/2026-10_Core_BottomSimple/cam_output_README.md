# Core 切削データ（MDX-540 / RML-1 / ATC）

生成: 2026-10-03。`cam.py` で生成し、`sim.py` の高さマップシミュレーション（0.2 mm格子）で検証。

## 座標
- 原点: 素材 100×100×15 の左手前角 = XY0、素材上面 = Z0。部品中心 X50 Y50。
- Inner/Outer は X軸回り180°反転配置（元モデル Z=-5 面が上）。
- 貫通深さ: 6 mm工具は Z-15.4、2 mmボールは Z-16.0。**捨て板が必須**。
- 工具が通る範囲は部品中心から半径47.2 mm以内。クランプは素材の四隅に置き、素材上面から+30 mm以下の高さにする。

## 条件
- T1: 荒取り F280、ランプ/溝 F180、仕上げ F250 mm/min、ap 0.3、ae 約1.1。仕上げ代 0.15。
- T3: F200、ランプ F150 mm/min、ap 0.15、ae 1.0（床部分は 0.3）。

## シミュレーションで分かった形状の差
- 歯溝（約1 mm幅）は2 mm工具が入れず加工されない（使用者が許容済み）。
- Innerハブ根元（r22、Z-8）にR1のすみが残る。床はモデルより0.02 mm高い。
- 部品への削り込みなし（STLの多角形近似による3 µm差を除く）。早送りで材料に接触する移動なし。

## 実行記録（2026-10-03）
- 初回送信は手動で設定した原点のずれ（+X 10 mm、+Y 5 mm）のため中止。今回限り `*_shiftX-10Y-5.rml`（全座標をX-10・Y-5補正）で再開した。
- 01の実行中にびびりとバリが出たため、03を `Core_03b_T1_outer_trochoid` に差し替えた。外周溝を全幅スロット（幅7 mm、ap0.3）から、トロコイド（幅8 mm、ρ1.0、1ループ0.4 mm送り、ap約0.96、F420）に変更。外周仕上げにはスプリングパスを追加した。推定時間は約185分。
- 02は変更していない。
- 01が完了したあと、02の先頭のJ3（ATC3への交換）で「Abnormal ATC air pressure」になり停止した。02と03bはキューから削除済みで、エアを復旧したら最初から送り直す。手順は `..\引き継ぎ_再開手順.md`。
