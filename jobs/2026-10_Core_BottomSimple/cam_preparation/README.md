# Core反転配置の確認用データ

`Inner_Core_inverted_preview.stl` と `Outer_Core_inverted_preview.stl` は、元のSTLをX軸まわりに180°回し、両方の底面をZ=0に揃えたもの。XY原点は元モデルと同じで、2部品を同心配置している。どちらも高さ15 mmで、2部品間の最小すき間は約4 mm。

これらは形状・工具到達性の確認用であり、実機用CAMパスやNCデータではない。精度が必要なCAMには `model` 内のSTEPデータを使用し、同じ変換をFusionで適用する。

`toolpath_geometry_preview.png` はSTL断面の輪郭（青）と、直径2 mm工具の名目上の中心位置（赤破線）を示す。左が反転Coreの上面、中央が下面側、右がBottom_Simple。Bottom_Simpleには中央穴に加えて外周から入る切り欠きがある。送り、切込み、タブ、工具保持、干渉は含まず、機械に送信できるパスではない。

使用者は2 mm工具で細い歯溝を通し、溝形状がつぶれることを許容した。したがって1 mm工具による細部仕上げは計画に含めない。2 mmボール工具が届かない細部は削り残しとなり、プレビュー中央の断面では原形状から最大約2.8 mmの差がある。

## 確認した加工順序の骨子

1. 100 × 100 × 15 mmブロックを捨て板に固定し、外周の10 mm程度の枠をクランプ領域に使う。
2. 中央10 mm穴と、Inner_Core／Outer_Core間の溝を上から加工する。最狭部4 mmには直径2 mmのロングネックボール工具を使い、細い歯溝は到達可能な輪郭まで加工する。
3. Outer_Coreの外径80 mmを切り出す。内外の部品が動かないよう、両部品と外枠の保持タブを先に設計する。
4. 工具・ホルダー・クランプの干渉、タブの強度、底面の抜けをCAMシミュレーションで確認する。

Bottom_Simpleの幾何順序は、2 mm板を捨て板に保持し、中央穴、外周の切り欠き、外周輪郭の順に加工する。最後の輪郭には保持タブが必要。切り欠きの幅は約5 mmなので、6 mm工具は入らない。

使用者が実機で設定したCoreのWCSは、扉側から見た素材左手前角をXY原点、素材上面をZ=0とする。100 × 100 × 15 mmストックなら、部品中心は名目上 X=50 mm、Y=50 mm、素材底面はZ=-15 mm。ここにある反転STLは形状確認用としてZ=0～15 mmに配置しているため、FusionのCAMでは元STEPを使い、WCSを実機の原点へ合わせる。工具ごとの刃径・刃長・首下長・ホルダー形状を実測登録する。Bottom_Simpleは別セットアップとして原点を設定する。

SS400はMDX-540の仕様対象外で、切削条件も未検証のため、この順序を実機へ送ることはできない。切削油はMDX-540の説明書で禁止されている。
