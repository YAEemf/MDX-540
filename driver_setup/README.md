# MDX-540 用 VPanel

1. [ローランドDG公式ダウンロードセンターの MDX-540/540S ページ](https://downloadcenter.rolanddg.com/MDX-540#software)を開きます。
2. 「VPanel for MODELA PRO II」の「Installer / インストーラー [Ver. 1.23]」を選び、使用許諾を確認してダウンロードします。
3. `VPanel-for-MODELA-Pro2_Installe.zip` を展開し、`VPanel for MODELA Pro II/setup.exe` を実行します。

同梱の Readme には、対応 OS として Windows 7、8、8.1、10 が記載されています。配布元の使用許諾に従い、ダウンロードした ZIP は Git の管理対象から除外しています。
